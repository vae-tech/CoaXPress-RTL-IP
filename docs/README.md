# `docs/` — documentation

| Folder | Contents |
|--------|----------|
| `spec/` | `CXP-001-2015.pdf` — JIIA CoaXPress 1.1.1, the standard the IP implements |
| `design/` | `modules_list.md` — one-line overview of every RTL module with links to its note; `cxp_rtl_map.html` — interactive RTL hierarchy, ports, nets, block diagrams, clock crossings, packages and register map |
| `design/modules/<group>/` | One engineering note per RTL module, grouped like `src/rtl/` (`app`, `cdc`, `tx`, `rx`, `ctrl`, `lib`, `top`, `pkg`); `pkg/cxp_regmap.md` is generated by `make regmap` |
| `style/` | `rtl_coding_style.sv` — the RTL coding-style guide, itself lint-clean (`make lint`, `make style`) |
| `verification/` | `cxp_verification_plan.md` — PyUVM verification plan (every test with description, stimulus, pass / fail criteria); `cxp_uvm_map.html` — interactive environment structure and test catalogue |
| `emulation/` | `cxp_emu_guide.html` — interactive guide to the emulator (host ↔ FIFO ↔ DPI bridge ↔ RTL): structure, layers, step-through transactions, packet lab, bench |
| `reviews/<yymm>/` | Dated reviews and reports (`*_yymmdd.*`); records of their day, not updated when the tree changes |
| `archive/` | Retired module notes and older reports |
