Environment, level by level

One graph per level, read from the code rather than drawn by hand. The env level shows every component CxpEnv builds, the test class (test) and the DUT harness as the bar on the left. A wire joins two blocks when one publishes to the other through an analysis port, drives or samples a harness pin the other also uses, calls into it through a handle, or starts a sequence on it; the number is how many such links. Double-click a block marked open › to see its driver, monitor and sequencers. Pick a test to see only what that test touches.

Scoreboard checks

Each scoreboard reports through err(kind, msg); the kind is what an EXPECT_FAIL tag names, and a test fails on any untagged kind. Kinds marked final are raised once at the end of the test (_final_check: expected but never seen). Meanings are from the plan's §3.3.

Functional coverage

Cells sampled by uvm/coverage/model.py at the end of every test into its cov_summary.json. make cov_gate merges a tier and fails on a goal cell no test hit. Cells that cannot be hit are listed apart, with the reason.
